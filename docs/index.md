## Publishing with GitHub Pages

## Introduction

Welcome to my Version Control Systems assignment on Publishing with GitHub Pages.

GitHub Pages is a service that allows users to publish websites directly from a GitHub repository.

## Objectives

* Learn how to publish documentation using GitHub Pages.
* Organize documentation using Markdown files.
* Create links between different documentation pages.
* Publish a live documentation website.
